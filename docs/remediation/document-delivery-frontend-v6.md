# Desktop document evidence: frontend

The desktop adapter can deliver a clean document reply while its bounded `kanit`
envelope retains measured checks, advice and actual change summaries. This change
only consumes that additive version-1 contract; it does not change verification,
model selection, permissions, CLI rendering or the classification of HTML as code.

`deliveryEvidence.ts` validates the optional `sunum`, `kontroller`, `olculmeyen`,
`oneriler`, `degisiklik_ozeti` and `ayrintilar_kisaltildi` fields. It masks known
secret forms, preserves Unicode character boundaries and caps detail text at 500
characters, detail lists at 10 entries, change summaries at 50 and the decoded
envelope at 32 KiB. Optional detail tails and trailing file entries are trimmed first.
Whole file paths are retained without shortening their identity; paths altered
by secret redaction are omitted, and byte trimming drops whole path entries.
Critical evidence that cannot fit produces an invalid, blocking card instead of
discarding problems or measurement gaps. Original total-path counts remain.

Document presentation is honored only for supported, verified, nonblocking
evidence with no false claim, problems, warnings or unmeasured checks and exactly
one retained static-document path matching the total path count. Native
closed `details` contain successful checks, advice and plain change summaries.
Problems, warnings and measurement gaps remain outside those details. File links
retain their existing behavior. The card inherits the conversation font rather
than imposing a larger size; expanded details contain their own scrolling.

Assistant history rows decode their saved `kanit`, including evidence-only rows.
Old rows remain unchanged. `VerificationPassed` and `ChangesDigested` now become
persistent activity steps, so the existing two-preview-row work panel retains
them. An incomplete or malformed verification event uses a neutral result label
and uncertain status. Measurement gaps precede successful checks in bounded
output. Change summaries never masquerade as unified diffs.
