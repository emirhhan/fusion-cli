# Short static reports and automatic planning

The observed ordinary current-source HTML report paid an automatic teacher phase solely because it wrote a file. The existing explicit self-contained-task exception requires special single-file and dependency wording which ordinary users need not provide.

The chosen change adds a narrow short static report exception to that mutation-cost decision. It requires affirmative brief-report scope, one literal static document target and a genuine requested workspace mutation. Read-only source URLs remain source data. Existing external/runtime/multi-file/teacher constraints, explicit broad or interactive scope, destructive operations and negated/quoted brief scope retain the existing route. Static text document suffixes are admitted; arbitrary subjects, source domains and output names are not special cases.

The shared bounded-task helper also retains its existing post-review deduplication: a second teacher review is skipped only when an eligible ordinary review actually ran and exactly one file changed. Explicit ordinary-review disablement still retains teacher review; voluntary/manual teacher calls remain available. Tool permissions, actual source/artifact evidence and verification are unchanged. A successful classifier test does not establish live model quality or task completion.

Implementation plan:
1. Add real policy and scripted AgentLoop regressions for ordinary TR/EN reports and source variants; run before source changes to observe the missing exception.
2. Add the smallest scope helper inside teacher_plan.py and apply it only to the workspace-mutation consultation reason.
3. Verify broad/interactive/destructive/multi-file/explicit-teacher controls plus existing teacher/source/effect/budget suites, Ruff and scoped mypy.
4. Commit owned paths and request independent review; no provider calls or installed/runtime changes.

## Validation and boundaries

The new helper requires one literal generated output with `.html`, `.htm`, `.md`, `.txt` or `.rst` suffix. A readonly input filename cannot stand in for that output. Filenames cannot themselves provide the brief-report adjective. Dotted subject names and versions remain topic data when their surrounding grammar identifies them as such. HTTP source addresses must satisfy the existing read-only source binding; unsupported protocols, including quoted operands, remain conservative in this new implicit-report route. The existing source matcher does not resolve a detached URL followed only by “read it”; that limitation is not widened here.

The existing explicit single-file/dependency route and existing small-document edit classification are retained. This is not a general natural-language complexity solver or a promise that every report avoids consultation.

Controlled RED runs reproduced the ordinary task and actual AgentLoop consultation cost, then additional input/output binding, scope and protocol findings. One initial non-mutation negative and one detached-source pronoun positive had invalid test preconditions; their failed logs were retained, their expectations corrected before final validation, and no production parser was weakened to pass them.

Final source validation, using `PYTHONPATH=src` and the original Python environment: **264 tests passed** across the new report policy plus bounded-task, source-report, teacher-first, teacher-plan, automatic phase budget, retry, mixed-current research, mixed-report source gate and research-source contract modules. The three actual AgentLoop controls cover normal review, explicit ordinary-review disablement and voluntary teacher access. Ruff and scoped mypy passed; no model, browser, native UI or network call was made.

Evidence: task workspace `work/reliability-v2/short-report-policy-frozen.log` and `.xml`; preceding RED logs are preserved alongside them. Real default-provider acceptance remains a parent task.
