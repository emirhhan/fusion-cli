# Current-fact research and artifact obligations

Three ordinary acceptance probes exposed a broader version of the mixed-effect
bug. Turkish current-version and weather reports could complete after writing a
file without research. English `Create report.html ... latest stable version`
was classified as research alone, so a source read could satisfy completion
without creating the artifact.

The policy now records an independent `requires_web_lookup` obligation alongside
its primary action. Explicit artifact work retains mutation priority and its
permission/verification requirements. English direct filename creation is
recognized without requiring the word `file`; Turkish `kaydet` binds to file
objects as a save action. Current-fact extraction distinguishes an output file
target (`rapor.html dosyasına yaz`) from a local input source, so creating a report
does not turn today's weather into a local-file fact. Quoted instructions remain
data; static/local/concept/translation/link-only/rejected/no-tools cases do not
invent a research obligation. URL paths and queries are masked before intent
classification and preserved unchanged for actual named-source matching.

Completion independently checks the action and research obligations. Named URLs
retain exact successful page-read matching. Generic research retains the existing
successful WEB-lookup semantics and also accepts the supported browser page
readers; browser controls/status and downloads do not prove lookup. Recovery asks
for the missing obligation and a bare continuation carries the genuine user's
compound scope. Actual mutation claims are still checked independently from the
research requirement, preserving truthful reporting of already-written files.

Evidence:

- Initial six policy regressions failed before changes, including all three exact
  root probes; additional URL-data and supported-browser-read probes also failed
  before their fixes.
- Nine actual-engine cases cover the exact three requests with write-only,
  lookup-only, and both. One-sided evidence fails; both obligations succeed.
- Thirteen adjacent product files passed 353 tests in 32.24 seconds; the final
  dedicated file passed 32 tests in 5.33 seconds, including three final negative
  browser-control/download controls. The broader run emitted one upstream
  Pydantic ReadOnly warning in the continuation admission test.
- Ruff check/format and full mypy passed for the four changed source files.

This proves actual action/lookup access, not the semantic truth, relevance or
freshness of an arbitrary page. Generic search evidence keeps its existing
contract; only explicitly named pages require a matching page read. Independent
Python/general review and an application rebuild remain pending. No original
checkout, installed app, runtime package or user configuration was changed.
