# K02/K08: one bounded review of a proposed factual issue

The required grounding seam can make one additional model call after a valid `issues` result. It does not turn an issue veto into a clean verdict. A replacement must pass the unchanged strict grounding parser, cover every original target, and explicitly mark every originally disputed target as `supported` with nonempty valid original source references. Any overlapping `uncertain` or `nonfactual` label on those targets prevents replacement.

Both calls use the same complete original target/source snapshot, digests, exact source/target span text and output schema. The second call receives only bounded structured proposed findings as explicitly untrusted JSON data. It cannot return edited claims, replacement spans, legacy headers or unknown output keys. The input snapshot is fingerprinted; mutation prevents acceptance. The ordinary source ownership, receipt completeness, span identity, full positive coverage and ordinal checks remain in place.

One absolute monotonic deadline is captured before the first call from the original request and current shared limits. Each call's transport timeout uses the remaining minimum of that absolute deadline and current shared deadline/hard/idle budgets. A late clean first result is incomplete, including when a transport swallows timeout cancellation. A late second result preserves the first issue. No remaining budget, oversized critique, oversized request, malformed/partial/truncated response, transport failure, renewed issue, unknown reference, edited qualifier field, mutation or incomplete disputed support also preserves the first issue. External cancellation propagates. There are never more than two calls per invocation.

The mechanism still relies on model semantic judgment. Nonempty valid references do not prove entailment, and retaining every qualifier in the exact input does not guarantee that a model reads it correctly. The second model can repeat an incorrect objection or incorrectly assess a qualifier. This change introduces no deterministic truth guarantee or translation allowlist, and it does not establish end-to-end research completion.
