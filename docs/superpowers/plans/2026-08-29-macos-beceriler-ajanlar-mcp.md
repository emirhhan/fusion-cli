# Fusion macOS E Aşaması — Beceriler, Ajanlar ve MCP Planı

## Hedef

Claude, Codex, Hermes, proje ve Fusion kaynaklarını tek native katalogda görünür ve güvenli biçimde kullanılabilir yapmak; kaynak dosyayı körlemesine çalıştırmamak.

## Görevler

- [x] Protokolde skill/agent/proje talimatı/MCP kataloğu ve güvenli detay okuma.
- [x] Oturumluk etkinleştirme/kapatma ve açıkça “sonraki turda kullan” sözleşmesi.
- [x] Agent döngüsüne filtrelenmiş capability registry ve görünür otomatik eşleşme olayı.
- [x] Figma tabanlı arama, kaynak filtresi, detay ve izin görünümü olan native katalog.
- [x] Sol navigasyondan gerçek ekrana geçiş; sohbet ve oturum durumunu kaybetmeden dönüş.
- [ ] Python/React/visual/paketli smoke kapıları ve E sonuç raporu.

## Kabul

- Yalnız bilgisayarda bulunan kaynaklar listelenir; aynı öğenin kaynakları `[claude+codex]` olarak birleşir.
- Skill ve ajan metni okunabilir, fakat komut/ağ eylemi standart araç onayını atlamaz.
- Oturumda kapatılan öğe otomatik eşleşme ve agent araçlarından gerçekten çıkar.
- Açıkça seçilen öğe yalnız sonraki tur için bütçeli sistem bağlamına eklenir.
- MCP sunucuları listelenir; oturumluk kapatma kalıcı config'i değiştirmez.
