# Kullanım Geri Bildirimi — İkinci Tur

Kaynak: 30 Ağustos, uygulamayı gerçekten kullandıktan sonraki bildirim.
Kullanıcının cümlesi: *"bunca eksik varken ben bu projeyi kimseye öneremem."*

Sıralama "ürünü bozuk hissettiren" maddelerden başlar; güzelleştirme sonra.

## A — Bozuk hissettirenler

- [x] **A1. Sohbet silme çok yavaş.** Sil'e basınca tüm ekranı kaplayan
      "bağlanıyor…" çıkıyor. Silme anında olmalı; çekirdek kapanışı arkada.
- [x] **A2. İzin modu arayüze yansımıyor.** Security'ye geçtim, görev kutusunun
      altındaki durum değişmedi.
- [x] **A3. Mod geçişi hiç çalışmıyor.** auto / plan / security arasında ne
      tıklayarak ne Shift+Tab ile geçilebiliyor; terminalde olduğu gibi olmalı.
- [ ] **A4. Anlamsız "/" girdisi.** "Yakın projeler" altındaki dosya ikonu ve
      "/" her tıklamada yeni görev açıyor; ne işe yaradığı anlaşılmıyor.
- [x] **A5. Kapatma onayı yok.** Pencere kapatılırken, Cmd+Q ve Alt+F4 dahil,
      "emin misin?" sorulmalı — yanlışlıkla kapatma iş kaybettiriyor.

## B — Eksik yetenekler

- [ ] **B1. Çalışma dizini sohbetin İÇİNDEN değiştirilebilmeli** (Claude Code
      nasıl yapıyorsa öyle), yalnız ayarlardan değil.
- [ ] **B2. Web sağlayıcılar kontrol panelinde düzgün görünmüyor.**
- [ ] **B3. Kontrol paneli**: arama çubuğu, model ekleme bölümü.
- [ ] **B4. Ayarlar derinliği**: sistem istemleri düzenlenebilsin, connector'lar,
      MCP bağlama yeri.
- [ ] **B5. Ses ayarları**: hız, robotik kademe, kullanıcının kendi ses dosyası.
- [ ] **B6. Ek önizlemesi**: ataçla eklenen görsel küçük önizleme olarak görünsün.

## C — Görünüm ve içerik

- [ ] **C1. Boş ekrandaki "pixel F"** yerine gerçek Fusion karakteri; duruma
      (düşünme vb.) göre ifadesi değişsin.
- [ ] **C2. Sohbet/Kod geçişi çok basit ve kırılgan duruyor**; referans olarak
      verilen Claude ekranındaki gibi olmalı.
- [x] **C3. Ana ekrandaki tema değiştirici KALDIRILSIN** — tema yalnız
      Ayarlar'dan değişmeli.
- [ ] **C4. Dersler işe yaramıyor**: yalnız "gönderilecek metin" yazıyor.
      Gerçek ekran görüntüleri, üzerine ok işaretleri ve "şunu şuradan yaparsın"
      anlatımı gerekiyor.

## D — Konuşma penceresi (ayrı tasarım turu)

- [ ] **D1.** Açılınca DOĞRUDAN dinlesin; mikrofona basma adımı olmasın.
- [ ] **D2.** Canlı dalga formu.
- [ ] **D3.** Küçük/büyük iki boyut, kullanıcı değiştirebilsin.
- [ ] **D4.** Her uygulamanın önünde kalma seçeneği (film izlerken bile).
- [ ] **D5.** Panel içinde ayarlar: saydamlık, ses hızı, kendi ses dosyası.
- [ ] **D6.** Onay soruları panelde cevaplanabilsin.
- [ ] **D7.** Karakter havada süzülür gibi yaylanan animasyon.
