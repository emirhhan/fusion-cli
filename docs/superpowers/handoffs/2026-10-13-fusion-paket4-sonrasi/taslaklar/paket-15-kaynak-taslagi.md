# Paket 15 — Gated protokol migration ve ileri işler blueprint'i

Salt okunur hazırlık, 13 Ekim 2026. Ana plan Paket 15, rapor `07-kaynak-ve-karar-defteri.md` D02/D05 ve `04-ortak-gelistirme-listesi.md` R34/R36/R39/R40 kaynaklarına dayanır. Sadece bu dosya yazıldı; ürün/test/build/live/credential işlemi yok. Bağımsız küçük P2 işler ilk günlük sürümü engellemeden capability/experimental gate altında kalır; R34 destek güvenliği kendi tamamlanma kanıtıyla değerlendirilir. Mevcut varsayılan model, `PRIORITY` routing ve ücretsiz sağlayıcı yolu korunur.

Kaynak doğrulaması: [MCP resmî 2026-07-28 duyurusu](https://blog.modelcontextprotocol.io/posts/2026-07-28/), yayın **28 Temmuz 2026**, erişim **13 Ekim 2026**; rapor07 kaynak URL'si doğrulandı. Yeni protokol initialize/initialized ve transport session header'ını kaldırır; version ve routing headers ile `_meta` taşır; discover isteğe bağlıdır. MRTR input_required ile etkileşim devam eder. SDK'ların destek açıklaması yerel kilitteki API'lerin doğrulandığı anlamına gelmez; implementation öncesi resmî SDK migration/API kaynağı exact hedef sürümle eşleştirilir.

1. Küçük `McpProtocolMode` alanı legacy/stateless2026; absent→legacy, unknown/future→unsupported. Explicit server/user migration seçimi + adapter_supported + fixture evidence birlikte; HTTP error/timeout sonrası mutation otomatik başka adapter'da replay edilmez. Transport türü tek başına protocol sürümü seçmez. Capability status requested/observed/unsupported/unknown ayrı; metadata güven verme veya remote-tool yetkisi genişletme değildir.
2. Yeni adapter'da initialize/initialized ve `Mcp-Session-Id` yok; `MCP-Protocol-Version: 2026-07-28`, `Mcp-Method`, applicable `Mcp-Name` body ile tutarlı; `_meta` client identity/capabilities. Optional `server/discover` yoksa geçerli normal request çalışır, destek unknown olabilir. Liste cache scope account/origin/protocol/capability key'ine bağlı; deterministic order/TTL geçerli, auth değişince invalidation. Raw token cache key/persisted meta olmaz.
3. MRTR supported gate ayrı: input_required normal tool completion değildir. Paket 5 immutable question/task/attempt scope ve cancellation→bounded continuation; late/duplicate answers yeni tool input yetkilendirmez. Continuation response replay server idempotency/receipt kanıtına bağlı; response lost external write Paket 8 OBSERVE_FIRST. Tasks/skills extensions advertise edilmeden supported yazılmaz; remote allowed-tools grant sayılmaz (Paket 7 origin/loading receipt).
4. Legacy fixtures: stdio ve HTTP initialize→initialized→list/call/close, token/OAuth, reconnect ve timeout; new fixtures no handshake/session header, required version/header-body mismatch, optional discover, unsupported extension, MRTR late answer/cancel, auth/account cache separation. Asıl SDK API desteklemiyorsa experimental disabled+clear unsupported; `mcp>=1.9,<2` içinde v2 davranışı varsayma.

- Bounded tests: `tests/test_redaction.py`, mevcut JsonSink/audit/doctor tests ve `app/src/feedback/report.test.ts`/FeedbackDialog testleri; nested dict keys/values, bearer short/long, vendor env names, refresh token, PEM multiline, encoded URL/userinfo, Unicode whitespace, homepaths, exception-tail sentinel. ## Recurring restart ve delivery: mevcut outbox + lease authority

Main `appserver/schedule.py` atomic `_store` ve `schedule_delivery.py::{add_delivery,pending_deliveries,acknowledge_delivery,store_lock}` mevcut outbox'tır: deterministic occurrence SHA(schedule,due), ack gelene kadar persisted, farklı task rebind reddi. App `useScheduleRunner::deliverPending/startDeliveryPolling`, `kits/scheduledDeliveryClient` ve Kits `client/scheduled-delivery-bridge` origin/window/nonce receipt kontratı zaten var. Kits `scheduled-delivery.ts::deliverSchedule/assertScheduledExecution`, `scheduled-delivery-store.ts::{stageRecord,activateRecord,migrateDeliveryScope}`, `Store.transaction/claim/owns/heartbeat/finish`, `Runner.tick/stop` aynı authority; yeni scheduler/delivery table kurulmaz.

1. Queued receipt yalnız durable accepted queue; completed değildir. occurrence aynı prompt/root/thread→aynı task `schedule-{occurrenceId}`; changed scope digest conflict. Permission intake + execution'da revalidate; eski eksik root/thread migration uydurmadan reddeder. App inFlight Set yalnız UI yarışını azaltır; backend durable dedup restart garantisinin kaynağıdır.
2. Cross-store stage→workspace.bindTask→activate crash noktaları ayrıca: transaction atomic aktivasyon, staged binding repair aynı scope ile; response lost→aynı occurrence retry ack, ikinci task/run yok. Task execution kimliği Paket 2 gonderim_id/receipt ile sabitlenir; schedule prompt mevcut purpose-specific store'da zaten var, onu yeni genel submission dedup ledger'ına kopyalama. New scheduling permission eski task'a broad grant olmaz.
3. Kits expired lease interrupted→queued ve `resumeNote` text mevcut; progress prose completed external effect kanıtı değildir. Running process gerçekten durmadan yeni owner effect yürütmemeli; owned cancel/liveness Paket 8, durable effect receipt/observe-first. Graceful stop release-before-abort yarışını test et; old lease finish/late events yeni lease'i tamamlayamaz. Crash accepted/running belirsizliği auto replay yerine recoveryRequired/probe; no claimed exactly-once arbitrary dış sistem.
4. Fake clock/DST/backward clock/due recurrence, iki process aynı due, fs-write crash, unmount/nonce late receipt, permission revoked, ack lost, stage/bind/activate crash, worker restart/expired lease/stale finish fixtures. Existing `tests/test_schedule_delivery.py`, `test_appserver_schedule.py`, App ScheduleScreen/scheduledDeliveryClient tests; Kits scheduled-delivery/routes/bridge/handoff-acceptance + store/runner tests genişler. Otomatik OS background çalışıyor etiketi yok: mevcut App yalnız açıkken poll eder; silent always-on ayrı explicit feature gate.

## Routing/cost ve recorded skill P2 sınırları

- `core/routing_strategy.py::order_models` mevcut otorite; COST_OPTIMIZED şu an `:free` proxy sıralaması ve PRIORITY default. `core/health.py`, `memory/performance.py::ChromaPerformanceMemory` task-type score/latency/timestamp; `observability/cost.py::CostTracker` ModelCallFinished toplamı. `providers/litellm_provider.py::_response_usage/estimate_cost` eksik usage veya bilinmeyen fiyatı şu an zero'ya indirir; Paket 7/9 typed unknown receipts ile düzeltilir. - Dataset önerisi existing feedback/performance metadata'ya schema/version+task type/requested/observed model/source/time/verifier outcome/retries/provider unavailable ayrımı; raw task/prompt yeni routing dataset'e yazılmaz. `ChromaPerformanceMemory.record` şu an documents=outcome.task kullanır; anonymized benchmark projection bunu export etmez. Öğretmen/fallback/invalid ayrı, küçük örnekten üstünlük ilanı yok. Explicit model override aynen, recommendation opt-in ve görünür; yeterli frozen benchmark olmadan otomatik varsayılan veya ücretli model geçişi yok. Unknown-cost modeli free diye sıralama; fiyat kaynağı/timestamp/currency+missing state, stale table bounded tests.
- `tools/capabilities.py::CapabilityRegistry/load_skill_text`, `capability_install.py::install` (pinned commit `fusion-yetenek.json`, script çalıştırmadan keşif), `engines/agent/learning.py` sensitive lesson rejection existing boundaries. Opt-in recording→ephemeral steps→sanitize+parameterize→user preview→atomic skill+origin/version/provenance receipt→mevcut catalog loading. Secret/personal path/URL/session/token/raw transcript ekranlar persist edilmez; tainted candidate reject/manual safe rewrite, yalnız regex “temiz” diye garantileme.
- Recorded skill safe placeholders izin vermez; remote allowed-tools/memory örneği immutable permission'i genişletemez; replay gerçek target scope Paket 5 ile yeniden onaylanır, browser/PID/login identity kayda gömülmez. No executable captured code auto-run, installer script execution yok. Feature gate closed until sentinel+path+injection/approval regression ve provenance review. Live demonstration/human permission testi ayrı; sır içeren gerçek kayıt testine gerek yok.
