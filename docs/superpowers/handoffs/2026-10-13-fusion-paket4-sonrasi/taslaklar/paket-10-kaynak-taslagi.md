## Minimal sözleşme ve mimari

1. **ImageJobReceipt.** Frozen additive core değer `(schema_version, job_id, parent_attempt, state queued/running/partial/completed/failed/cancelled, operation, flow/node/variant identity, asset_ids, requested_count/completed_count, stage, error code, cancel_requested, remote_effect_unknown)`. Legacy `gorsel.olustur` terminal dosyalar cevabı korunur, additive jobId/receipt; yeni start/status/cancel endpoints aynı runner'a adapter, ikinci provider engine değil. Paket 2 durable request ID same retry dedup, Paket 9 artifact ref authority reused. Shell `JobCompletion` process evidence ve image provider job aynı şey değildir: common receipt/owner/atomic helpers reuse, görsel işi Popen'a zorlanmaz.
2. **Ownership/progress.** AppSession mevcut owned task yaşam döngüsünü (Paket 8) `(session, image_job_id)` ile inject ederek başlatır; cancelled old job yeni işi kapatmaz. queued account lock bekleme, generating, validating, committing asset gerçek stages. Job finished ancak validated file+metadata commit+receipt sonrası; output files birer birer committed olduğunda retained. UI AbortSignal dependent client wait ve next-variant admission durdurur; host cancel aynı job'a idempotent ack+cleanup terminal; web/API request cancel edilebilir ama remote execution unknown honest field. Stop sonrası yeni varyasyon başlamaz, üretilmiş asset silinmez. Provider page/HTTP cleanup owned await; outliving external response Paket 8 observe-first/idempotency, automatic replay yok.
3. **Execution scope.** Mevcut `akisiCalistir` graph plan projeksiyonu kalabilir; authoritative validation ve node/variant receipt backendde her accepted execution için yapılır. Tam server flow execution gerekiyorsa aynı validator+render_images+owned task adapter, browser executor ile ikinci karşıt scheduler değil; bir authority seç, UI sadece snapshot/progress projection. En küçük teslim: backend node-job authoritative, UI graph navigation async loop abort checks, server validate_flow execution snapshot kabul eder; reconnect node receipts'ten devam. Flow revision/job snapshot immutable, running editor değişiklikleri bir sonraki iş.
4. **Server DAG validator.** Raw ID'yi kesmeden bounded nonempty unique doğrula; known node/fields strict types, finite x/y, integer count mevcut 1..4 sınırı (invalid silently drop yok), bounded prompts/provider/ratio IDs. Edges endpoint unique/self/duplicate/typed ports/cardinality; tüm graph Kahn visited_count==nodes cycle gate. Required inputs/edit reference presence; execution scope ancestors correctly validate, unreachable disconnected operations kullanıcıya görünür. GUI eklenti tarafı aynı static contract fixtures, server authoritative. Asset path sadece gallery canonical owned asset-ID resolver, secret/outside/symlink escape reject; parent asset revision actual hash/availability checked immediately before provider upload. Missing target as generate fallback yok.
5. **Atomic flow persistence.** Paket 8 same-dir unique temp/flush/platform-supported fsync/replace helper, expectedRevision locked CAS reuse; flow content version/store revision ayrı. New client stable flow ID duplicate-save same receipt, mevcut ID optional legacy adapter; invalid save eski flow değiştirmez. Load v1 known migration, future schema unsupported; backend sanitized flow hidden UI-only output fields unknown ise migration policy açık. Rename failure old file retained, conflict UI draft retained+diff/reload (Paket 3 AsyncState). Async I/O off eventloop, typed okfalse/error in UI.
6. **Tek byte validator.** NIM ve web aynı image payload/file validation helper'ı çağırır: strict base64, finite bounded byte count/dimensions/pixel count (limits mevcut yapılandırma/kanıtla, yeni sayı uydurma), Pillow verify ardından reopen+full load, actual format/MIME/width/height/alpha metadata. HTML/login/json hata payload image olarak commit olmaz; magic prefix tek başına yeterli değil. `tools/image_ops.describe` mevcut gerçek decode metadata yardımcısı incelenir fakat sadece Image.open header tam doğrulama değildir; provider→tools katman importu ekleme. Ortak core saf ImageMetadata/validator protocol gerekirse, concrete provider decode/write helper iki provider için tek; tools metadata okuyucusu ikinci generation validator olmaz. Unique ID/exclusive filename, same-dir atomic image publish; commit önce validation, half-file gallery scan'a düşmez. Decode data actual JPEG ise .jpg/MIME doğru; target extension değişimi açık conversion yoluyla, rename byte change değil.
7. **Capabilities unknown.** Existing ImageChoice additive operation support/exact_size/reference count/seed/alpha/mask/upscale modes evidence tri-state supported/unsupported/unknown+source/revision. Web configured≠authenticated verified; legacy bool facade korunur, UI bilinmeyeni destekleniyor diye açmaz. Capability-required reference/edit server gate. Oran requested hint vs exact-size parameter vs decoded delivered dimensions ayrı; requested 1024 actual768 görünür, exact guarantee yok. Native upscale yoksa mevcut reference regeneration adı korunur; unsupported mask edit bölge hint diye açıklanabilir, native diye sunulmaz. Yeni provider/spec defaultları eklenmez.
8. **Seed/lineage.** NIM mevcut random generator injected seed source, requested seed explicit geçerli range doğrulanır; adapter model truly supports ise body ve observed seed receipt; unsupported/unknown params silent ignored değil. Web seed null/unknown; aynı seed her hesap/model/sürümde aynı sonuç garantisi değildir. Metadata sidecar version `(asset_id, operation, reference ids+roles+revision, requested/applied model/provider/account-safe-id, prompt policy, requested ratio/size, decoded dimensions/format/alpha, requested/applied seed, job/node/variant, created/observed clock, revision)`; prompt mevcut consent/retention/redaction sözleşmesine göre, secrets genişletilmez. Image atomik publish fakat metadata failure output kaybolmuş gibi regenerate etme; receipt orphan/recoveryRequired olarak tutup metadata recover. Reuse bütün bilinen alanları kurar, unknown alan invented default değil.
9. **Partial ve variant seçimi.** Node state partial ayrı; completed yalnız requested variants valid committed. Failure after1/3 asset retained+partial badge+cause; UI flow tamamlandı dememeli. Stable variant slots/input revision; “eksikleri tamamla” yalnız missing slots (same parent job new explicit attempt) ve existing assets unchanged; explicit full regenerate farklı eylem. Selected asset-ID node output downstream reference, first-result implicit seçimi legacy migrate edip görünür chosen default yap; selected missing asset job durur. Provider bir invocation çok image döndürürse slot/count semantics açık, overcount/node duplicate receipts yok.
10. **Basit/ileri UI.** Existing mod state korunur; basit prompt/model/ratio/visible target, capability-relevant options; seed/flow/lineage ileri bölüme. Edit entry reference thumbnail/name/revision ve chosen operation görünür; kullanıcı hedefi yanlışken sessiz generate yok. Paket 3 independent provider/gallery/flows AsyncState+retry/generation, save/run pending synchronous ref guard, immutable running snapshot. Account queue aşaması gerçek receipt, wait timeout/cancel action; exactsize label requested/delivered ayrımı. Gallery partial/error still valid assets; same job update merge by asset ID, replay prepend duplicate yok.
11. **Viewer/gallery.** Gallery asset-ID cursor pagination (stable timestamp+id) bounded page, actual dims valid sidecar+file metadata, missing/corrupt row per-asset error. Existing `list_gallery` compatibility full list küçük caller için gerekirse, large UI cursor API; new manifest/index sadece 10k scan ölçümü gerektirirse existing asset metadata storage authority genişler, ikinci gallery registry değil. Selection index yerine asset ID; prepend/delete/deferred load yanlış resmi açmaz. Existing dialog focus pattern reuse: initial focus effect open-ID'de, focus trap, Escape, opener restore, tab/arrow navigation ve descriptive alt; image load error retry. Delete mevcut safe trash authority, active flow references warning+explicit policy, receipt history GC silent loss yok. K33/P2 sayfalama/trash ayrı ölçülü alt teslim olabilir.
