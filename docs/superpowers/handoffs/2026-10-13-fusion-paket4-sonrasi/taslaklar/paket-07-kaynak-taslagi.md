Kaynak: plan Paket 7, E09–E14/E23–E26, R19–R21, A20/A21. CLAUDE.md/RULES.md okundu. Salt okunur inceleme; ürün değişikliği, test çalıştırması veya credential okuması yapılmadı. R22/R23 öğretmen açıklaması/ders invalidation ayrı P2 teslimidir; MemoryPanel bu pakette yeni ders motoru almaz.

- `engines/agent/team.py::schedule_waves` ham `Path(raw)` karşılaştırıyor: `a/../b`, `b`, symlink alias aynı alana paralel yazabilir. `derive_sub_context` parent `write_scope` yerine child bildirimini koyuyor; dar parent genişleyebilir. `tools/files.py::resolve_path/writable_path` gerçek canonical erişim otoritesidir; `restrict_to_root=False` yolunda ayrıca `.resolve()` gerekir. `extra_roots` açık parent erişimidir; yeni child grant değildir.
- `run_subagent` Started yayımladıktan sonra persona/context/run hatasında terminal yayımlamıyor; boş metni placeholder ile `outcome.ok` başarı sayıyor. `run_team` TaskGroup içinde exception bağımsız kardeşleri iptal ediyor. Child `AgentDeps` oluşturulurken `budget`, `execution`, `deadline` aktarılmıyor; her child yeni tur sınırı kurabilir.
- `loop.py::_drive` model çağrısını yanıt geldikten sonra `record_model_call` ile sayıyor. Sadece aynı bütçeyi taşımak eşzamanlı çağrı sınırını korumaz: birkaç child son hakkı aynı anda görebilir. `TurnBudget` çağrı/doğrulama/süre otoritesidir; `context_budget.py` bağlam penceresidir, takım kotası değildir.
- `ToolContext.touched/changes` ortak; paralel child sonucu için `after-before` farkı kardeş değişikliklerini de sahiplenir. `write_scope` kullanımı yalnız `writable_path` içinde bulundu: shell ve uzak mutasyon için ilan edilmiş dosya alanı teknik sandbox değildir.
- `CapabilityRegistry::_merge` aynı adın ilk içeriğini tutup sonraki `source` etiketlerini birleştiriyor; içerik eşitliği kontrol edilmiyor. `get_skill/get_agent` ilk ad eşleşmesi; origin/version/kimlik yok. `capability_install.py` zaten `fusion-yetenek.json` içinde commit kaydediyor: bunu yeniden üretme.
- `map_tools` bilinmeyenleri sessiz düşürüyor; boş veya tek `*` tam set, yalnız bilinmeyenler boş set. Bu compatibility ayrımı korunmalı. `search_scored/_score` ASCII kelime bölmesi Türkçe çekimleri/diakritikleri kaybediyor; kısa substring hatası geri gelmemeli.
- `load_skill_page` offset dışında revision yok; dosya değişince eski/yeni sayfalar karışır, okuma hatası başarı metni olur. `engine_tools::_read_skill_tool` ana/ref okumalarını ayırıyor fakat loading receipt yok. Katalog `detail()` okuması modele invocation değildir.
- `expertise.py::expertise_hint` registry yerine bundled dizini ve ilk hardcoded kuralı okuyor; implicit context gerçekte yüklense de olay yok. Remotion/Godot ayrımı ve `MAX_EXPERTISE_CHARS=4000` mevcut ölçümlü sınırlarıdır.
- `core/types.py::TokenUsage` sıfır varsayılan; LiteLLM `_response_usage` usage yoksa aynı sıfırı döndürüyor. `ModelResult.usage` mevcut taşıma otoritesi; unknown ile gerçekten 0 ayrılmıyor. ContextGauge gerçek input ölçümü/pencere ile turn token toplamı birbirinden ayrıdır.

## Tasarım kararları ve arayüzler

1. **Tek canonical scope hazırlığı.** `team.py` normalizasyonunu `tools/files.py` otoritesine bağla: scope köke göre çözülür, canonical containment parent erişimi ve parent yazma alanıyla doğrulanır. Child alanı parent altındaysa kabul; geniş/karışık yetki isteği açık hata, sessiz truncate yok. Parent `None` sınırsız ilan alanı, `()` yazma yok; child boş alan parent sınırını devralır, read-only child `()` + dar araç seti alır. Parent/child canonical scope kümesi yalnız daralır. Zamanlayıcı ve araç enforcement aynı hazırlanmış scope'u kullanır; stringlerle ikinci hesap yok. Geçersiz scope hiçbir child başlamadan reddedilir; yazma anında validator yeniden çözerek değişen symlink'i kontrol eder.
2. **Dosya dışı etkiyi doğru söyle.** Dar scoped child'a hedefi validator ile denetlenemeyen shell/remote mutating tool'u açma; Paket 5/6 effect+target resolver ile kanıtlanabilir araç daraltma uygula. “scope var, dolayısıyla shell sandbox” iddiası yok. Read-only araç seçimini dinamik effect metadata ile doğrula; remote annotation tek başına izin değildir. Mutasyon yetkisi parent approval/policy kesişimi; persona/skill allowed-tools grant oluşturmaz.
3. **Tipli tek terminal.** `SubRun` additive `status` (completed/failed/cancelled/budget_stopped), blocker/error_code, canonical scope, actual changed_paths, evidence references, validation status alanları; `ok` compatibility projection. `SubAgentStarted/Finished` additive parent/sub/group/attempt correlation ve bu özet alanlarını taşır. Parent-child kimlikleri Paket 2 event-id/dedup sözleşmesine bağlanır. Boş nihai metin tek başına başarı değildir; doğrulanmış artifact/evidence varsa tipli başarı mümkündür. Child success ana doğrulama success anlamına gelmez.
4. **Yaşam döngüsü tek yerde.** `run_subagent` Started sonrası owned try/except/finally terminalini tam bir kere üretir. Beklenen failure/exception child sonucuna çevrilir, sanitized code kullanılır; parent `CancelledError` terminal yayımlandıktan sonra tekrar yükseltilir. Kullanıcının yalnız bir child'ı durdurması owned child task içinde sonuç olarak yakalanır; kardeşlere yayılmaz. `run_team` kendi TaskGroup/task map sahibi kalır; yeni scheduler/runtime yok. Map owner AgentDeps/turn sahibine inject edilir, host additive child cancel `(attempt_id, sub_id)` yalnız yaşayan aynı parent çocuk için idempotent ack verir; parent cancel tüm task'ları cancel+await eder. Queued başlamamış işler ayrı cancelled result alır, sahte Started yayımlanmaz.
5. **Ortak bütçe, atomik admission.** Child `deps.require_budget()` nesnesini, immutable turn execution/deadline'ı devralır; child policy parenttan genişlemez. `TurnBudget` içinde model-call hakkını await öncesi reserve eden saf/senkron işlem; event loop içinde check+increment bölünmez. Failed/timeouts/cancel sonrası harcanan gerçek invocation geri verilmez; mevcut sayaç semantiği ve testler açık migrate edilir. Verify take zaten senkron; tüm parent/child/self-review aynı defter. Provider call/retry/fallback fiziksel çağrı sayımı mevcut adapter yoluyla açık tanımlanır; yalnız dış logical sonucu sayıp kesin fiziksel tavan iddia etme. Shared deadline task'ları gerçekten iptal eder, durma nedeni parent raporuna gelir. Tek child failure global budget.stop yapmaz.
6. **Kanıt sahipliği.** `ToolContext`a additive child attribution observer/owner-id; ortak `ChangeSet` rollback/verifier otoritesi kalır. Başarılı gerçek mutasyon kayıtlarında owner+path ile child actual changed_paths toplanır; shared touched kümesinin farkından çıkarılmaz. Shell artifact kanıtı yoksa unknown, model beyanı actual değişiklik değildir. `_team_report` tamam/yarım yerine açık status/blocker/evidence ve parent verification-needed projeksiyonu verir.
7. **Takım kapasitesi.** `max_parallel_agents` aktif concurrency otoritesi korunur; toplam task sayısına ayrı config sınırı ve schema maxItems, yeni sayı uydurulmaz. Mevcut stable input-order sonuç korunur. `schedule_waves` canonical scope ile çalışır; okurların arka arkaya çakışan yazıcılardan dolayı beklemesini gideren stable earliest-compatible wave yerleştirmesi, belirsiz yazıcının mevcut solo-barrier anlamını korur. E14/P2 ayrı küçük alt teslim olabilir, zorunlu P0 scope/terminal işi bekletmez.
8. **Katalog kimliği ve version.** `Capability` additive origin-id, qualified-id, version nullable, content_revision, provenance/trust. Origin gerçek yerel/proje/plugin/kurulu/MCP kaynağı; kurulu commit mevcut manifestten, plugin sürümü varsa metadata'dan, bilinmeyen null. İçerik hash'i sürüm etiketi değildir. Aynı içerik kanıtlanırsa kaynaklar bir ortak satırda görülebilir, farklı içerikli aynı ad ayrı satır/explicit collision. Legacy bare-name yalnız tekilse çözülür; collision için belirsiz hata ve qualified seçim. Disabled/selection config eski ad migrate edilerek bütün aynı adlı origin'i yanlışlıkla grant etmez; host katalog/detay/seçim etkinlik ve UI key qualified-id kullanır. Yeni MCP skill discovery/2026 extension handshake Paket 15; burada origin modeli hazır, olmayan remote katalog icat edilmez.
9. **Araç ve arama teşhisi.** `map_tools` compatibility facade korunur; typed diagnostic kardeş helper mapped+unknown verir. Unknown araçlar görünür; boş/* eski davranışı ayrı test, sadece unknown listesi fail-closed boş set. Catalog “izinler” bildirilen ihtiyacı gösterir, verilmiş yetki değil. Türkçe locale normalization/ASCII alias ve küçük açıklanabilir çekim eşleşmesi `search_scored` içinde tek otorite; kısa sözcük substring skoru yok, ölçülü fixture corpus ile yanlış eşleşme sınırı doğrulanır.
10. **Sayfalama ve loading receipt.** Typed SkillPage(text, revision, offset, next_offset, truncated, error) aynı read helper; offset>0 beklenen revision zorunlu, uyuşmazlık restart-required. Reference ayrı revision taşır ve canonical `skill_file` escape guard korunur. Engine prompta gerçekten eklenen ana sayfa/implicit hint/user explicit selection için `SkillLoaded` event `(attempt, agent, qualified-id, version/revision, mode, page range, truncated)`; catalog preview/find result receipt oluşturmaz. Reference read ek kanıt olarak receipt'e bağlanır, ana skill tekrar invoked sayılmaz. Yükleme adım uygulandığını/tamamlandığını kanıtlamaz: executed-step/validation ancak gerçek tool/verification evidence varsa ayrı alan. İçerik receipt'te saklanmaz.
11. **Implicit seçim.** `expertise_hint` registry catalog ve mevcut specificity/exclusion metadata ile tek güçlü, güvenli skill seçer; çelişen güçlü eşleşmelerde none ve açıklanabilir gerekçe. 4000 toplam prompt sınırı (prefix dahil) korunur. User-selected skill `AppSession::_take_capability_context` sonraki kabul edilen Paket 2 submission için snapshot+revision ile tüketilir; rejected/busy submission seçimi kaybetmez. Kullanıcı seçimi ile implicit hint aynı skill ise bir receipt, context tekrar yok. Child/reference yalnız gerekli sayfa yükler.
12. **Usage unknown ayrımı (E12 additive alt iş).** `TokenUsage`a additive measured/completeness (ve cost-known ayrı) veya nullable ölçüm alanları; backwards integer facade unknown'u 0 başarı diye sunmaz. Provider genuine usage varsa measured zero geçerli, web/eksik input/output unknown/partial. `TurnBudget` observed totals+unknown call count bir kez çağrı kimliğiyle toplar; retry/duplicate event tekrar toplamaz. Token sınırı kullanım sonrası soft-stop olabilir; unknown veya streamde anlık usage yokken kesin hard token tavanı garantisi yok. Known observed lower bound ve complete/partial görünür; context char estimate/token-window ölçümüyle birleştirilmez. Sağlayıcı maliyeti tahmin, fiyat bilinmiyorsa free etiketi yok.
