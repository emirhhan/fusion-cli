# Paket 9 — Kanıtlı kapanış ve çalışma akışı blueprint

Kaynak: Paket 9/R11–R16/R24/U22/U23/U25/E35. Salt okunur hazırlık; ürün edit/test/credential okuması yok. Paket 2 ID/dedup, Paket 4 model evidence, Paket 5 soru, Paket 7 skill/usage ve Paket 8 resume/cancel receipt kontratları tüketilir. Mevcut agent/runtime/verifier/TurnReport otoriteleri genişletilir; ikinci completion engine/store yok. E35 loop refactor ayrı davranış koruyan alt değişikliktir.

## Kaynakta mevcut otorite ve açıklar

- `cli/session.py::run_agent_task` mevcut runtime closure'da `outcome.ok`→completed, aksi halde gerçek `tool_context.changes.paths` varsa partial/diğer failed; `TurnOutcome` ardından `TurnFinished` yayımlar. `core/events.py::TurnOutcome` status+elapsed taşıyor; TurnFinished yalnız lifecycle, model prose başarı değildir. `cli/repl/loop.py` closure'da NoFileChanges/FilesChanged/TurnFinished var; aynı finalization projection bütün yüzeylerde kullanılmalı, yeni agent engine yapılmamalı.
- `engines/agent/turn_report.py::TurnReport` changed_paths, gerçek CommandRun, VerificationResult, behavioral evidence, false_claim ve job_deliveries otoritesi. Paket 1 job/source freshness defteri bu otoriteyi güçlendiriyor; listeleri yeniden hesaplayan UI kapısı yapılmaz. `evidence_payload` şu anda nullable doğrulandı/engelliyor/yanlış_iddia ve ilk 50 path/10 problem; schema/receipt/model/artifact/control metadata yok, truncation bilgisi yok.
- `loop.py::_apply_turn_report` `report.render()` boşsa early return ile blocks_success uygulamasını atlıyor. No changed paths/no jobs fakat gate failure veya false claim kombinasyonu için regression fixture gerekli; display boşluğu safety sonucunu belirlememeli. Report false-claim regex defense-in-depth, yeni completion için model metni ana status input olmaz.
- `NoFileChanges` docstring “dosya/sistem değişikliği yok” diyor; gerçek karar `AgentOutcome.made_no_changes`/mutation sayacı ve ChangeSet farklı kapsamlar. Shell/remote etkiler dosya path listesinde görünmeyebilir. Dosya değişmedi ile hiçbir dış etki olmadı ayrılmalı; `changed_paths` tam kapsanmayan shell/workspace değişikliği unknown kalabilir.
- `core/artifacts.py::ArtifactStore` büyük redacted tool output depolama/owns erişim otoritesi; bu bir teslim artifact registry değildir. Aynı session counter/path restartta collision riski ayrı metadata identity ile ele alınır, yeni raw output deposu açılmaz. `core/evidence.py::CriterionEvidence` artifact/command/output ve behavioral alanları mevcut; capture provenance/site capture kayıtları viewport/source için mevcut başlangıç, screenshot presence kalite geçişi değildir.
- `AppSession::_run_turn` `kanit` yalnız RPC cevabına ekliyor. `useSessions::baslatRef` sonuçtan metin+ok false alıyor, kanit kayboluyor. Model stream final/protocol result iki kanaldan gelebilir; Paket 2 final/event-id dedup sözleşmesi aynı attempt receipt'e bağlanmalı. Accepted final/selected candidate otoritesi `loop.py::_announce_answer`; rejected candidate transcript'a düşmemeli.
- `olayMetni.ts::TurnOutcome` unknown/future status'u failed olarak gösteriyor. `Conversation` mesajları tüm map, outer index keys; Paket 2 stable Mesaj ID çözümü kullanılır. SentAttachments span/img açma eylemi yok; hooks `useStickToBottom` enAltaIn fonksiyonunu zaten döndürüyor fakat Conversation kullanmıyor. User-send boolean son role'den türetiliyor, prepend/history/session switch gerçek yeni kullanıcı submission değildir.
- Mevcut `Conversation.perf.test.tsx` 800 mesaj ilk render için <2500ms ölçümlü CI sınırı; bütün stream güncellemesinde eski Markdown/ActivityLine maliyeti ayrı ölçülmemiş. `useStickToBottom` resize gözlem/pinned ref koruyor. `ChangesPanel` refresh race/pending rollback ve revision-target doğrulaması eksik; `PreviewPanel` file load generation guard/object URL cleanup mevcut, URL sadece local preview; sırf açılabilir link diye hosted key/token URL veya arbitrary file okutulmaz.
- `appserver/context_gauge.py::baglam_olcusu` history-char compression % ile genuine last input tokens/window ayrı; ContextGauge bu ayrımı gösteriyor. Prompt assembly `loop.py::_initial_messages`+`read_all_instructions`, `repo_map_block`, extra_system, expertise ve history gerçek kaynak kullanım noktaları. Katalogda bulunan/arama sonucu bağlama eklenen demek değil.

## Tasarım ve kontrat

1. **Tek runtime closure.** Frozen typed CompletionReceipt additive `(schema_version, receipt_id, session/conversation/attempt, status, stop_reason, elapsed, changed_paths with coverage, artifacts, verification receipts, unresolved requirements, model receipt ref, context sources, effect receipt refs)`. Status existing completed/partial/failed ve Paket 8 cancelled/recoveryRequired semantiğine açık uyum; duplicate generation tek final ledger identity. Verifier/TurnReport outcome'dan bir projection üretir; model “bitti” cümlesi, completed todo listesi, TurnFinished veya RPC ok true receipt status'unu yükseltmez. Display yoksa da `blocks_success` uygulanır. Generic partial sadece dosya path'ine bakmaz: gerçekten teslim edilen artifact/external effect + unmet requirement partial, hiçbir geçerli teslim yok failed; unknown effect success olmaz. Mevcut kullanıcı soru/plan/chat başarılı terminali “uygulama teslimi doğrulandı” rozeti almaz.
2. **Receipt doğrulama.** Gate failure/son mutasyon sonrası başarısız davranış/no behavioral evidence gerekli işte engeller; syntax-only/static/unknown ayrı. Proof her kontrol için target/source revision, run/tool-call ID, exit/status, zaman, evidence reference; exit0 tek başına bütün testlerin geçtiği iddiası değil, gerçekten koşan kontrolün sonucu. Cancel/timeout/ambiguous effect Paket 8 status'u preserved. Final report block semantics doğru, `render` görüntü kararı ayrı. `NoFileChanges` yalnız doğrulanmış dosya değişiklik kapsamını anlatır; remote effect/no mutation/unknown workspace coverage ayrı kayıt ve metin.
3. **Artifact evidence kartı.** Typed ArtifactReference yeni veri tipi (mevcut output ArtifactStore backend'i ve image/file/job capture kaynaklarını adapter ile tüketir); identity/source owner attempt, kind, canonical path veya validated URL, revision/hash, MIME, created/observed time, viewport width/height/device/DPR varsa nullable, originating tool/verification IDs. Model metninden “asset oluştu” çıkarma yok. Existence/hash fresh observation gerekli; missing/stale/wrong attempt screenshot görsel verified olmaz. Artifact metadata export'ta secrets/raw output/URLs query redacted; private contents explicit open yalnız mevcut host workspace/artifact owns validator yoluyla. Core tipe stdlib, veri toplama adapter tools/engine içinde, generic ArtifactStore'a yeni image provider iş mantığı eklenmez.
4. **UI teslim projeksiyonu.** Tek DeliveryCard existing Conversation yanında receipt status+somut teslim/control/findings/model; yeni Mesaj rolü yerine additive receipt veya küçük ayrı rol mevcut reducer convention'a göre. Receipt-ID stable key, payload revision latest; event+RPC aynı receipt'i merge, duplicate final/body yok. Legacy kanit schema yoksa explicit legacy limited/unknown evidence; future schema unknown unsupported, success/failure uydurma yok. Partial findings açık, completed checkbox modelinin altında verified badge otomatik değil. Sınırlı payload lists count/truncated+lazy detail ID ile açılır, UI eksik son path'i tam liste sanmaz.
5. **Dosya/URL/screenshot açma.** `SessionApplication` mevcut onOpenFile/onOpenPreview→ChangesPanel/PreviewPanel yolları reuse; receipt target revision ile selection, stale varsa “geçmiş kanıt/mevcut dosya farklı” distinction, eski screenshot current state diye etiketlenmez. External URL sadece approved opener route; PreviewPanel local iframe boundary korunur. File/image attachment klavye button, image büyütme existing dialog+focus restore/Escape; missing/read denied onOpen Promise typed result/pending/error/retry, span→button yeterli ama void callback hatayı bildiremez. Submitted attachment identity Paket 2'den, aynı path farklı revision ayrı.
6. **Önce/sonra kanıtı.** `ChangesPanel` ChangeSet öncesi/diff/current revision otoritesi, external action undo iddiası yok. Screenshot before/after aynı target ve capture contract revision, viewport match yoksa karşılaştırma unsupported/warning; video kare timecode/oyun gerçek control observation varsa metadata, yoksa sahte capability yok. Bu yeni öğretmen/ders veya asset editing motoru değildir. Panel per-request generation+AsyncState ve rollback pending target revision Paket 3 adapter reuse; kullanıcı doğrulaması son mutation'da stale olursa yeniden onay.
7. **Zaman çizelgesi.** Existing ExecutionStep*/RepairAttempt*/Checkpoint/RetryScheduled/Question/SkillLoaded events gerçek phase ve reason; ActivityLine/ToolTrail aynı projection. Polling/probe/duplicate output ilerleme sayılmaz; provider wait gerçek geçen süre, yüzde/veri yoksa invented % yok. Parent/child lanes Paket 7 stable IDs; TurnOutcome status final lane, lifecycle flush statusu yükseltmez. R14 resume/cancel receipt kartına link Paket 8'den, transcript undo ve code restore ayrı.
8. **Soru kalitesi R15.** Paket 5 typed required/preference/skip/resolved evidence aynen kullanılır; turn receipt yalnız soru purpose/key, dependent action blocker, repeated/previous answered attribution aggregate metadata gösterir. Üç tur fixture'da verilen teknoloji tekrar sorulmaz, missing account external write blocker, “sen seç” açık preference+assumption rationale. İkinci question classifier/scheduler bu pakette kurulmaz; mevcut decision ledger permission/preference ayrımı korunur.
9. **Bağlam kaynakları R16.** Prompt assembly sırasında actual included source IDs+origin/revision/kind/explicit-or-implicit/truncated/range, history summary boundary, lesson IDs kaydedilir; read değil genuinely model request'e included receipt. Instruction shadow/collision resolver Paket 7 evidence metadata; content varsayılan kapalı. Araç output offloaded ise contextte preview+artifact reference, bütün output “kullanıldı” etiketi değil. Her model call source set farklı olabilir, turn union+call ref açık; catalog preview/find usage değil. ContextGauge compressed-char ratio genuine token usage değildir, Paket 7 unknown usage/probe purpose korunur; source içerikleri sırf liste için persistence'e çoğaltılmaz.
10. **Scroll unread.** `useStickToBottom` additive pinned/hasNewContent/count/jump projection; pinned enAltaIn mevcut davranış korunur. Stable last-seen message/event cursor; kullanıcı yukarıda yeni streaming/new receipt gelirse tek yeni içerik indicator, her chunk binlerce mesaj saymaz. Unread sadece append/new-content, prepend history veya panel detail resize değil. Accepted new own submission ID ile jump, role boolean değil; history restore/session switch remembered anchor+scroll state. Jump explicit button aria label/live polite summary, focus çalmaz; reduce-motion instant streaming. Görsel load/geç markdown büyümesi pinned ise takip, unpinned anchor korunur.
11. **Ölçerek performans U25.** Mevcut 800/2500 fixture baseline; 800/large history markdown+diff+teams+stream delta/profiler ölçümü implementation sırasında. Stable IDs ve completed message memoization, sadece active stream slice değiştir, son olay reverse/reduce scans gerekirse state projection; threshold büyüterek failure saklama yok. Gerekirse explicit “önceki mesajları yükle” bounded history page, prepend anchor korunur; search/selection/focus/details state/assistive tech erişimi kaybolan kör virtualization yok. Protocol/transcript retention ile render bounds ayrı; source evidence detail lazy, no permanent giant base64 card payload.
12. **R24 reçeteler ayrı küçük P2 alt işi.** Existing `config/skills/templates`+EmptyState entry gerekli capability/permission, typed deliverable/control planı kurar; site viewport+interaction, video render, ads account/read permission, fix source+behavior gate. Sadece marketing prompt ve tek domain hardcode değil. Kullanıcı recipe seçimi mevcut accepted submission+skill receipt, tool grant artırmaz. Resmi değişken paid-media platform/spec verification implementer taskında güncel primary kaynakla; blueprint teknik kontrat scope'unda dış current claim yok.

## Kabul/test matrisi

- Engine ok fakat report.blocks_success/gate failure/no changed paths fixture→wrong success yok; syntax-only vs behavioral, failing test after latest mutation, successful test before later write stale; successful completed chat vs verified deliverable ayrı. NoFileChanges actual file-scope-only, remote effect/unknown shell not “nothing happened”; partial accepted artifact+unmet requirements, false model prose never upgrades. Runtime final status ile RPC completion receipt aynı.
- Selected candidate accepted final bir kere, rejected candidate Stream/Finished/body transcript'a düşmez; duplicate/out-of-order TurnOutcome/TurnFinished/RPC final single card/body; stale attempt ignored Paket 2; future schema/status explicit unknown, legacy limited nullable verification retained. Budget/cancel/recovery required not misleading completed.
- Actual artifact existing/hash fresh, missing screenshot/source changed/wrong attempt/stale viewport receipt no visual approval; screenshot verified requires real verifier evidence; unsupported video/game evidence unknown. Metadata secret sentinel/query tokens redacted; raw content not receipt. Truncated lists count+lazy detail correct.
- File/image/URL open keyboard/pending/failure/retry/focus restore; canonical escape/symlink/owns denied; local web preview boundary; matched before/after viewport/revision and changed current file explicit; rollback request stale target refuses, external effect not undone by code rollback.
- Unpinned streaming/post-image load scroll anchored, unread button appears and jumps/clears; own accepted new submission jumps, rejected draft/history prepend/session restore no unwanted scroll; message detail/copy state IDs survive prepend. Aria updates bounded, keyboard focus and selected text preserved.
- Context sources genuine included calls only, catalog preview/find excluded, reference/page truncation accurate, history condensation source range and lesson IDs no private content; charset %/window/actual unknown token separated. Polling and health probe no progress counter, model waiting no artificial percentage; three-turn question fixture R15.
- Perf baseline 800 same 2500ms unchanged, heavy history stream update measured before/after; bounded render only warranted, load older anchor/no skipped transcript/find/search/a11y selected text. E35 extraction event order, permission/verification gates, stop reason, repair ledger/source freshness parity snapshots in separate task.
