Missing file listeden düşer, provenance/parent reference tombstone korunmaz.
- `image_flows` gallery sidecar prompt/provider, list_gallery tüm dizini stat/read; Paket 10 actual format/dimension/seed+asset ID migration önkoşul. `core/artifacts.py::ArtifactStore` redacted büyük tool çıktı/owns otoritesi; `core/assets.py` iş asset inventory verifier'ıdır, gallery authority değildir. Buraların adından yeni kapsam çıkarıp üçüncü registry açma.
- `assetUrl.ts` sadece Tauri convertFileSrc, decoder/authority değil. LibraryScreen yol/dimension/source UI, direct reveal, cast payload; allowlist resolver önce hostta olmalı. `workspace.resolve_workspace_path` proje dosyası otoritesi; gallery/library/uploads bağımsız izinli kökler aynı rule ile role-scoped resolver'da birleşir. Tauri assetProtocol scope UX için destek, origin/session/task authorization yerine geçmez.
- Kits pages content Markdown string+shared types, typed asset reference bridge yok; `host-theme.ts` parent source gate var fakat origin gate yok. `kits-host.ts::kitsHostOrigins` açık HTTP(S)/Tauri origin policy; `folder-pick-bridge`/Main FolderPickHost origin+parent window+nonce doğru örnek, path iframe tarafından önerilemez. `KitsScreen` existing host adapters lifecycle ve iframe ref reuse edilecek.
- Main `theme/tokens.css` mevcut semantic light/dark ve compatibility aliases canonical palet. Kits `scripts/kits-dark-theme.mjs` style/editor/kits CSS'yi postcss renk heuristic ile generated CSS yapıyor, DARK_FLOOR/RANGE ayrı değerler; semantic meaning eşleşmesi garantisi yok. `prepare-kits.mjs` sibling Kits bundle+Node24 runtime paketler, runtime gate mevcut; tema/bridge manifest sürümü yok.

## Minimal ortak kontrat

1. **Tek asset otoritesi.** Paket 10 metadata ve mevcut library JSONL authority aynı asset registry adapter altında genişler: stable opaque `asset_id`, `metadata_version`, kind/MIME, storage namespace+relative_path, created_by_task/attempt nullable, parent_asset_ids, revision/content_hash, provenance/created/observed, state ready/missing/tombstoned/corrupt. Dimensions/alpha/provider/model/seed sadece decoded/observed ise nullable, unknown sayıyla doldurulmaz. Image sidecar existing generation record canonical provenance; library index derived searchable projection, yeni ikinci authoritative gallery DB değil. Büyük çıktı ArtifactStore record aynı registry'ye owned reference adapter; raw output redaction/owns unchanged.
2. **Identity/migration.** Asset ID filename veya content hash değildir: aynı bytes iki bağımsız üretim ayrı asset, aynı dosya revision değiştirebilir. Bir kez legacy canonical namespace+path mapping transaction ile ID ata, sidecar/indexe aynı ID yaz; App chat/gallery/Kits page roundtrip aynı mapping. Existing references yol compatibility adapter resolver ile map; legacy task/provider/parent/seed bilinmiyorsa unknown, model metninden provenance icat etme. Parent silinince lineage parent-ID+tombstone korunur, missing downstream reference Paket 10 açık hata. Absolute path public bridge'de dönmez; old path read backward allowed only host approved scope, new clients asset IDs.
3. **Resolver ve path allowlist.** Host profile/workspace/session bound asset_id→namespace→canonical allowed root+relative path. Existing workspace validator canonical root/symlink/extra-roots rules reuse; gallery/upload/artifact-own namespace explicit read roots. Reject absolute/.. encoded/Windows separator drive escapes, symlink outside, arbitrary raw path bypass; missing/changed revision typed. Imported user chosen upload yalnız picker-authorized copy once; registry path attacker-supplied read grant değildir. File stat/hash/decode open boundary race kontrollü, content MIME validator Paket 10; URL retrieval same origin/authorized handler, token/query data opaque capability URL veya stream response, metadata logs no secrets. Resolver write/edit/export ayrı Paket 5 grant, read trust yazma izni değil.
4. **Atomic storage/projection.** Paket 8 unique-temp/fsync/CAS helper asset metadata/index updates; immutable asset publish validated bytes first, registration fail orphan recovery explicit, double regenerate yok. JSONL append transaction/revision/unique mapping durability policy; gerekirse same registry SQLite projection/index same authority, migration idempotent. Index corruption recovery approved directories+sidecar scan, generated workspace roots sadece kayıtlı scoped refs, bütün home taraması yok. Scan no invented task/parent provenance; deleted/tombstone records resurrect edilmez. JSONL bad-line diagnostics, future metadata unsupported quarantined, incomplete transaction detectable; asset receipt D01 lifecycle korunur.
5. **Pagination total order.** Cursor `(created_or_sort_time,asset_id)`+query/filter/snapshot revision, stable ordering descending time+ID. Mutable mtime yalnız display/current revision, cursor stable creation identity veya snapshot ile page boundary; concurrent insert üst sayfaya, ongoing cursor duplicate/miss yok. Library index+gallery canonical asset-ID dedup before count, filter count same authorized dataset, cursor version/future schema fail explicit. UI bounded page+load-more perquery generation/AbortSignal Paket 3/11, ID selection keeps viewer asset when prepend. 10000 gallery measured latency, lazily decoded thumbs/details no whole base64 payload. Refresh recovery index scan ayrı user-visible phase, fallback silent empty değil.
6. **Host asset bridge backward.** Existing KitsScreen host adapters ve Kits origin policy+nonce request/result pattern extend; capability handshake additive `(bridge_version, supported asset schema versions, operations resolve/list/insert/export, cancellation)`; new protocol matrix Paket 15, burada legacy message handlers kırılmaz. Old host no asset support→explicit unavailable+legacy safe path adapter ancak existing authorized boundary varsa; arbitrary convertFileSrc URL Kits'e transfer etme. New host/old Kits old folder/computer/theme paths unchanged. Request qualified owner/session/page/attempt target, reply nonce+generation, teardown abort/cancel listener/timer cleanup Paket 11. Asset insertion content URI/ref same ID and revision, Page CAS actual expectedRevision; dirty draft agent patch conflict unchanged, bridge asset cannot overwrite page without grant. HTTP service and iframe postMessage both consume same resolver authority, duplicate upload/insert receipt Paket 2.
7. **Chat→gallery→page roundtrip.** Image receipt existing asset ID, gallery card same ID, Kits insert page attaches typed asset reference/portable asset URI (Markdown adapter manifest handles relative resolved URL). Renderer asset URI resolved host safe endpoint; standalone Kits no host clear unavailable, copies only user-authorized import. Editor reference metadata version+revision safe, export Paket 11/12 manifest same ID parent lineage; missing asset placeholder+retry no broken path fake generated image. Native browser/system URLs only at authorized renderer adapter, not persisted absolute-path portability claim.
8. **Shared tokens tek kaynak.** Main existing semantic tokens remain canonical authored source; stable machine-readable manifest or deterministic CSS variable extraction includes light/dark surfaces/text/borders/accent/focus/spacing/type/motion and alias map/version. Generate App/Kits consumable CSS+manifest from that source, no two manually maintained palettes. Kits existing dark generator imports semantic palette and maps remaining legacy hardcoded colors as temporary compatibility; migrate touched components semantic vars, postcss generated output never manually edit. Generator reproducible/idempotent stale-artifact check, sibling absence consumes versioned bundled canonical manifest not ambient parent filesystem assumption; package script copies exact manifest/checksum. Main current aliases preserved until caller migration, component behavior React-independent.
9. **Theme bridge.** Current host theme initial query+live theme message stays, additive tokens version+capability; Kits validates parent window AND allowed host origins via existing policy, unsupported theme version safe default+notice, no arbitrary CSS remote injection. Switch without iframe reload preserves chat/editor drafts. Embedded host semantic theme preferred, standalone own preference; shared contrast/focus/reduced motion behavior spec maps each frontend adapter. Tests assert semantic alias resolution and light/dark focus/selected text contrast existing measured tokens, not screenshot color heuristic alone.
10. **Comments/compare küçük alt görev.** R28 new optional UI metadata `(annotation_id, asset_id, revision, coordinate_space, normalized rect/point, text, author scope)` storage existing asset authority; view zoom/device transform only renderer projection, annotate screenshot revision vs current mismatch visible. Before/after same lineage/viewport/revision explicit, accessible slider/buttons keyboard+focus+screenreader labels, no first/last image implicit compare. Masks native supported only capability evidence Paket 10; unsupported region is instruction hint, unknown no false edit support. Comments text never permission grant/model correctness proof; typed attachment context only explicit user submission, private annotation no unsolicited export.
