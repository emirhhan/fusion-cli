Bu panel ne yapar

Bu panelden API anahtarı girebilir, yedek (fallback) zincirini düzenleyebilir, yönlendirme stratejisini değiştirebilir ve modelleri test edebilirsin. Uzak sunucu yok — her şey burada, sende kalır.
1Kendi kurduğun ya da erişim yetkin olan OpenAI-uyumlu bir uç kullan (OpenWebUI, LibreChat, LM Studio sunucusu, kurumsal uç…). Ticari web arayüzü (ChatGPT/Gemini web) desteklenmez.
2Endpoint: ucun sohbet adresi — çoğunlukla .../v1/chat/completions ile biter. Uygulamanın "API" ya da "Bağlantı" ayarlarında yazar.
3Token (varsa): ucun ayarlarındaki API anahtarı / bearer token. Yerel kurulumlar çoğu zaman token istemez — boş bırak.
4Kaydet. Sonra Yönlendirme sekmesinden bu modeli zincire ekle; artık bir model gibi kullanılır.

Yönlendirme stratejisi

priority = ölçülmüş sıra (varsayılan). free_first = ücretsizler önce. headroom = en sağlıklı önce. round_robin/random = dağıt.

Gelişmiş / güvenlik notları
Fusion normal Chrome profilini okumaz. Her sağlayıcı/oturum için ayrı profil kullanır. Cookie, config.yaml veya loglara yazılmaz. Web modeli araç çağrısını metin olarak üretir; dosya, shell, web search ve kod düzenleme işini Fusion'ın kendi izinli tool runtime'ı yürütür.
Dosya değiştirme izni: web modeli araç çağrısını METİN olarak üretir. Bunu güvenilir yapıp yapmadığı ölçülmeden dosyalarına yazmasına izin verilmez. Ölçüm 5 gerçek istek gönderir ve kendi aboneliğinden harcar.
